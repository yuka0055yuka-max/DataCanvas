# 📊 DataCanvas - グラフ可視化PWA

**教育・業務・研究に使える、表形式編集＆グラフ描画対応のPWAツール！**  
CSV・TXTインポート／エクスポート、統計表示、グラフ切り替え、オフライン対応まで全部入り。

🔗 公開URLはこちら → [https://yuka0055yuka-max.github.io/DataCanvas/](https://yuka0055yuka-max.github.io/DataCanvas/)

---

## 🚀 特徴

- ✅ 表形式でデータ編集（年・値など）
- ✅ グラフタイプ切り替え（折れ線・棒・円・散布図・レーダー・積み上げ棒）
- ✅ 統計表示（平均・最大・最小）
- ✅ CSV / TXT インポート＆エクスポート
- ✅ Chart.jsによる高性能グラフ描画
- ✅ PWA対応（スマホにインストール可能＆オフライン動作）

---

## 📱 PWAとして使う方法

このツールはPWA（Progressive Web App）対応なので、スマホやタブレットに**アプリのようにインストールせずに使えます！**

### ✅ iPhoneの場合
1. Safariで [https://yuka0055yuka-max.github.io/DataCanvas/](https://yuka0055yuka-max.github.io/DataCanvas/) を開く  
2. 画面下の「共有」ボタンをタップ  
3. 「ホーム画面に追加」を選択  
4. アイコンと名前を確認して「追加」→ 完了！

これでホーム画面からアプリのように起動できます📱✨

---

## 🧠 使い方

### 1. 表形式でデータ入力
- 「＋ 行を追加」で年と値を入力
- 「🗑️」ボタンで行を削除

### 2. グラフ表示
- グラフタイプを選択（折れ線・棒・円など）
- 「グラフ更新」ボタンで描画

### 3. ファイル操作
- CSV / TXT ファイルを読み込んでグラフ化
- 編集したデータをTXT形式で保存可能

### 4. 統計表示
- グラフ下に「平均・最大・最小」が自動表示されます

---

## 📊 対応グラフタイプ

| グラフ | 用途 |
|--------|------|
| 折れ線（line） | 時系列データ |
| 棒（bar） | 比較 |
| 円（pie） | 割合 |
| 散布図（scatter） | 相関分析 |
| レーダー（radar） | 多項目比較 |
| 積み上げ棒（stacked bar） | 構成比変化 |

## 🛠 技術構成

- HTML / CSS / JavaScript（Vanilla）
- Chart.js（グラフ描画）
- FileReader API（CSV/TXT読み込み）
- Blob API（エクスポート）
- localStorage（履歴保存）
- Service Worker（PWA化）
